# ProTimer v2.7.0

**Check for updates** is now at the bottom of Control. A check looks for the latest stable GitHub release. You choose when to download its platform package and when to open it. The app verifies the size and SHA-256 from GitHub before opening the installer and keeps the installer closed while a timer, audience output or online share is active.

## Upgrading from an older version

- **Windows Setup** — close ProTimer and run the latest Setup. Keep your existing installation folder. Your settings and rundown stay in place.
- **macOS Apple Silicon** — close ProTimer, open the DMG and replace ProTimer.app in its current location.
- **Windows portable** — close ProTimer and replace the portable EXE with the new portable EXE.

After this upgrade, future checks can start from Control. ProTimer opens the downloaded Windows Setup or Mac DMG. On Mac, confirm the replacement yourself in Finder. The unsigned Mac distribution uses the system's normal installer prompts.

The release includes dedicated **In-app update package** assets. GitHub counts downloads per asset. Those totals estimate update downloads. They do not identify users, count unique devices or confirm installation. ProTimer adds no analytics account or installation reporting.

## Srpski

**Proveri ažuriranje** je u dnu Kontrole. ProTimer proverava poslednje stabilno izdanje na GitHubu. Ti biraš kada se preuzima i kada se otvara paket. Aplikacija proverava veličinu i SHA‑256 pre otvaranja. Instalacija se otvara kad su tajmeri, izlazi i online deljenje ugašeni.

Za prelazak sa starije verzije, zatvori ProTimer i pokreni Windows Setup u istom folderu ili na Macu zameni aplikaciju iz DMG-a na njenom postojećem mestu. Za prenosivi Windows zameni stari EXE novim prenosivim EXE fajlom. Podešavanja i rundown ostaju sačuvani. Posle prelaska na 2.7.0, nove verzije proveravaš iz same Kontrole.

GitHub broji preuzimanja posebnih paketa za ažuriranje. To je procena broja preuzimanja i ne pokazuje broj korisnika koji su završili instalaciju.
