# ProTimer v2.6.0

- **Multiple displays.** Assign Timer 1, Timer 2 or both to each extended display. Send one output or the whole assignment from Control. Reuse the same two clocks for any number of independent outputs supported by your computer.
- **HDMI keying.** Choose black for luma key, or green/blue for chroma key on a compatible switcher. The keyed output shows only white digits. Blackout hides the digits while preserving the key color. [Roland and ATEM guide](https://github.com/srdjankotarlic/protimer/blob/main/docs/MULTI-DISPLAY-KEYING.md)
- **Stream Deck XL.** The bundled plugin installer enables connection and retries after the Elgato confirmation. Activate the editable XL profile manually once the device appears. [Setup guide](https://github.com/srdjankotarlic/protimer/blob/main/docs/STREAM-DECK.md)
- **Ten digit styles.** Find the classic default, Pixel, Cyber and seven others under **Control → Colors → Digit font**. The choice is saved and carries through to audience displays and the browser.

## Downloads

Choose Windows x64 Setup, Windows x64 portable or the macOS Apple Silicon DMG from the assets below. Each desktop build includes the native Stream Deck plugin. The standalone plugin and SHA-256 checksums are available separately.

The release workflow checks both packaged desktop builds. Native output rendering is checked with captured pixels and the seven-display layout is covered with a simulated display inventory. A physical HDMI chain and a Stream Deck XL are evaluated on the equipment being used.

## Srpski

- **Više ekrana.** U Kontroli dodeli svakom ekranu Tajmer 1, Tajmer 2 ili oba. Pošalji pojedinačno ili sve dodeljene ekrane.
- **Pozadina za svičer.** Izaberi crnu za Luma ili zelenu/plavu za Chroma. [Uputstvo za Roland i ATEM](https://github.com/srdjankotarlic/protimer/blob/main/docs/MULTI-DISPLAY-KEYING.md#srpski)
- **Stream Deck XL.** Klikni **Instaliraj plugin i poveži**, potvrdi u Elgato aplikaciji i zatim ručno aktiviraj XL profil.
- **Deset fontova cifara.** U meniju **Boje → Font cifara** su dosadašnji font, Piksel, Sajber i još sedam stilova.
