Speaker communication

Set warning colors, overtime, and speaker messages

The stage display should communicate urgency at a glance without pulling attention away from the talk.

Warning thresholdsOvertimeSpeaker messages

Choose simple warning thresholds

A practical starting point for a 20-minute session is yellow at 5:00 and red at 2:00. Shorter talks need proportionally shorter thresholds. ProTimer lets you choose both times and colors, or turn warning colors off.

Session lengthYellowRed
5 minutes1:300:30
15-20 minutes5:002:00
45-60 minutes10:005:00

These are starting points, not rules. Confirm them with the stage manager or client before the event.

Decide what happens at zero

  • Overtime on: the display continues below zero so speaker and crew can see the overrun.
  • Overtime off: the countdown stops visually at zero.
  • Flash at zero: adds a stronger visual cue; use it only when appropriate for the room.
  • Sound at zero: belongs on the operator machine, not an audio path that reaches the audience.

Use short speaker messages

Messages sit below the main timer, so keep them brief and unambiguous. Useful examples:

5 MINUTES
WRAP UP
LAST QUESTION
PAUSE
THANK YOU

Use on-screen text such as BREAK when you want to replace or supplement the normal timer for the audience. Use the speaker-message field for private confidence-monitor direction.

Rehearse the tone: speakers react better when they know the color sequence and messages before going on stage. Include the timing rules in the speaker briefing.

Keep control actions obvious

  • Put Clear Message next to the message buttons.
  • Make Blackout visually distinct and test its active feedback.
  • Do not place Reset next to GO without a clear label or button guard.
  • Give the operator +1 minute and -1 minute controls for live corrections.
