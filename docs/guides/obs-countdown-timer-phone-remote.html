OBS and phone workflow

Add a free countdown timer to OBS and control it from your phone

ProTimer serves a clean browser output for OBS and a separate token-protected remote for the operator. Both follow the timer running on the show computer.

OBS Browser SourceSame Wi-FiNo account

1. Open the network panel

Start ProTimer and open Network - OBS / Phone. The app shows a Timer URL, Remote URL, Backstage URL, and API URL. The port is normally 7878, but ProTimer automatically chooses the next free port if needed.

2. Add the timer to OBS

  1. In OBS, choose Sources + -> Browser.
  2. Paste the view-only Timer URL shown by ProTimer.
  3. Use a 16:9 size such as 1920 x 1080, then fit the source to the canvas.
  4. Turn on Transparent background in ProTimer for a clean overlay over video.
Keep ProTimer open: the Browser Source is a live local view served by the app. Closing the app also closes the timer server.

3. Open the phone remote

  1. Connect the phone and ProTimer computer to the same trusted Wi-Fi network.
  2. Open the Remote URL or scan its QR code.
  3. Test Start/Pause, Reset, time adjustment, GO, blackout, and speaker messages.

The Remote link contains a session token. Treat it as a control credential and do not put that QR on the audience screen. ProTimer only allows view-only Timer and Backstage QR links to be shown publicly.

Production checks

  • Disable client isolation on the production Wi-Fi or use a network where devices can reach each other.
  • Keep the OBS computer wired when practical.
  • Re-copy the Remote/API link after restarting ProTimer because the control token changes each launch.
  • Use LAN for show-critical timing; Share Online is a beta convenience for off-site viewers.
