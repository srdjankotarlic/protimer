OBS setup in four steps

Keep ProTimer open on the show computer and connect over the same local network.

1

Copy the Timer URL

In ProTimer, open Network → OBS · Phone and copy the view-only Timer address, such as http://192.168.1.50:7878.

2

Add Browser Source

In OBS, add a new Browser Source to the scene and paste that URL into its URL field.

3

Choose the look

Turn on Transparent background in ProTimer for an overlay, or leave the background solid for a full-frame timer.

4

Run a rehearsal

Test white, yellow, red and overtime states, plus blackout and text, while watching the final program canvas.

Keep control private: OBS needs the Timer URL, not the Remote URL. The Timer page is view-only; the Remote link contains the session token used for operator commands.

Build a reliable show setup

A few production habits prevent most Browser Source problems.

Use the local address

For a show-critical OBS source, use the LAN URL displayed by ProTimer. Keep the ProTimer computer and OBS computer on a network you control.

Open ProTimer first

The local page is served by the desktop app. If ProTimer closes or its IP changes, refresh the Browser Source with the new address.

Rehearse state changes

Confirm the transparent background, warning thresholds, fonts and NOW/NEXT layout in the actual scene resolution before doors open.

Need NDI or another screen?

ProTimer does not emit NDI directly. Add the Timer URL to OBS first, then send the finished OBS scene through an NDI output such as the DistroAV plugin.

The same local web output can also open in a normal browser on another computer or TV, while the Backstage URL provides the full NOW/NEXT schedule for the crew.

OBS stage timer FAQ

Answers for common production setups.

Is the OBS timer free?

Yes. ProTimer is free and open source, and the Browser Source output has no watermark, account or subscription.

Can OBS and ProTimer run on different computers?

Yes, when both computers can reach the local Timer URL. Use a stable production LAN and test the address before the show.

Can I show only the digits?

Use the transparent background for an overlay and leave optional NOW/NEXT and text elements off. Resize and position the Browser Source inside OBS.

Why is the Browser Source blank?

Confirm ProTimer is open, paste the current Timer URL again, verify both computers are on the same reachable network and refresh the OBS Browser Source.
