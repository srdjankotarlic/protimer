# ProTimer v2.8.1

**BLACKOUT now previews the selected mode in Control.** With **Hide content · keep background**, the timer and overlays disappear while the chosen color or transparency stays. The checkerboard indicates transparency. **Black screen** shows a solid black preview. You can switch modes while BLACKOUT is active. Press BLACKOUT again to restore the content. Both modes leave the timers running.

When the configured background is solid black, both modes produce a black audience picture. The Control badge shows which mode is active. HDMI keying outputs keep their assigned key color so the switcher continues to remove it.

Timer 3's stopwatch preview now reads its own elapsed time. Thanks to [Manuel](https://github.com/srdjankotarlic/protimer/issues/67) for reporting the blackout problem.

## Srpski

**Kontrola sada prikazuje izabrani BLACKOUT režim.** Kada izabereš **Sakrij sadržaj · zadrži pozadinu**, nestaju tajmer i ostali elementi, a izabrana boja ili providnost ostaje. Šahovnica označava providnost. **Crn ekran** prikazuje punu crnu pozadinu. Režim možeš promeniti i dok je BLACKOUT uključen. Sledeći pritisak na BLACKOUT vraća sadržaj, a tajmeri nastavljaju da rade.

Ako je izabrana pozadina već crna, oba režima daju crnu sliku publici. Oznaka u Kontroli pokazuje koji je režim aktivan. HDMI izlazi za Luma i Chroma key zadržavaju dodeljenu boju.

Ispravljen je i pregled štoperice Tajmera 3, koji sada prikazuje svoje proteklo vreme.
