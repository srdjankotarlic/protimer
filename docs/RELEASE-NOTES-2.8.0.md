# ProTimer v2.8.0

ProTimer supports up to three independent timers. Enable **Show third timer** in Control when you need it. Each timer can display a countdown, a stopwatch or a clock. The third timer has its own duration, start, pause, reset, live adjustments and zero alerts.

Open **Route to multiple displays**. For each extended display, choose a single timer, any pair (1 + 2, 1 + 3, 2 + 3), or all three. Pick side by side or stacked for grouped outputs, then send one display or all assigned displays. The app remembers assignments and opens outputs when you send them. Rundown continues to use Timer 1. The supplied Stream Deck profile controls Timers 1 and 2.

Already on ProTimer 2.7.0? Select **Check for updates** at the bottom of Control. For earlier versions, run the new Windows Setup in the existing folder or replace the Mac app from the DMG. [Display setup](MULTI-DISPLAY-KEYING.md)

## Srpski

ProTimer sada ima do tri nezavisna tajmera. U Kontroli štikliraj **Prikaži treći tajmer** kad ti zatreba. Svaki tajmer može da prikazuje odbrojavanje, štopericu ili sat. Treći tajmer ima svoje trajanje, start, pauzu, reset, izmene vremena uživo i upozorenja na nuli.

Otvori **Raspodela na više ekrana**. Za svaki prošireni ekran izaberi jedan tajmer, bilo koja dva (1 + 2, 1 + 3, 2 + 3) ili sva tri. Izaberi podelu levo/desno ili gore/dole i pošalji pojedinačni izlaz ili sve dodeljene. Dodele se pamte, a izlaze otvaraš ručno. Rundown koristi Tajmer 1. Priloženi Stream Deck profil upravlja Tajmerima 1 i 2.

Ako koristiš 2.7.0, klikni **Proveri ažuriranje** u dnu Kontrole. Sa ranije verzije pređi pokretanjem novog Windows Setup-a u istom folderu ili zamenom aplikacije na Macu iz DMG-a. [Uputstvo za izlaze](MULTI-DISPLAY-KEYING.md#srpski)
