# ProTimer v2.6.1

This update makes the Control window easier to scan and fixes rundown behavior around cue changes and expiry.

- Keep the timer controls and rundown in view. Expand messages, display routing, window placement, appearance and sharing when needed. Press **M** to open and focus the message field.
- Auto-advance respects changes to the rundown order even when the current timer has just reached zero.
- A cue confirmation expires when the timer is reloaded, including when the same cue is reloaded. Loading and starting a cue updates the live view in one step.
- With overtime disabled, the last cue stops at zero. Planned times stay anchored across midnight while Control remains open.

The native Stream Deck plugin is included in the macOS Apple Silicon and Windows x64 downloads. Download the installer and matching SHA-256 file from the assets below.

## Srpski

- Kontrola je preglednija. Poruke, izlazi, izgled i povezivanje otvaraju se po potrebi. **M** odmah otvara polje za poruku.
- Automatski prelaz prati redosled stavki čak i ako se izmene baš kad vreme istekne.
- Ponovno učitavanje tajmera poništava prethodnu potvrdu. Učitavanje i start stavke su jedna promena prikaza.
- Kada je minus posle nule isključen, poslednja stavka staje na nuli. Planirani raspored zadržava isti datum preko ponoći dok je Kontrola otvorena.
