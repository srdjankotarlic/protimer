# ProTimer OBS Browser Source Checklist

Use this with the exact OBS scene collection and network planned for the event.

## Setup

- [ ] Open ProTimer and keep it running on the show computer.
- [ ] Open `Network - OBS / Phone` and copy the view-only Timer URL.
- [ ] In OBS, add a Browser Source and paste the Timer URL.
- [ ] Set a 16:9 source size such as 1920 x 1080, then fit it to the scene.
- [ ] Enable `Transparent background` in ProTimer when the timer should overlay video.
- [ ] Confirm the OBS source updates when Start/Pause, Reset, and time adjustment are used.

## Network

- [ ] Keep the OBS/ProTimer computer and phone on the same trusted network.
- [ ] Confirm the phone can open the view-only Timer and token-protected Remote URLs.
- [ ] Do not show the Remote QR to the audience; it can control the timer.
- [ ] Re-copy Remote/API links after restarting ProTimer because the token changes each launch.

## Pre-show

- [ ] Test warning colors, zero behavior, overtime, speaker messages, and blackout.
- [ ] Disable sleep, notifications, and automatic updates.
- [ ] Save the OBS scene collection after the Browser Source is working.
- [ ] Prefer LAN for show-critical viewing; treat Share Online as a beta fallback.
