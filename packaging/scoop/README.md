# ProTimer Scoop manifest

This manifest is prepared for a future proposal to the Scoop Extras bucket.
It is not submitted because the current package-request form requires a project
to be reasonably well known (approximately 100 stars or 50 forks) before a
maintainer approves manifest work.

The manifest uses the official versioned portable Windows asset and includes
GitHub-based version detection and autoupdate metadata. Re-check the current
Scoop contribution policy, artifact checksum and portable-data behavior before
submitting a future proposal.
