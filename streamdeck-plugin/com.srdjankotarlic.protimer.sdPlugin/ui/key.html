ProTimer Key

Pair in ProTimer Control → Stream Deck. No IP or token is needed here.

Following Control. To customize only this physical key in Elgato, select “Edit here” below. Control layout changes will no longer overwrite it.

Copy both IDs from the Control editor. Linking does not move or claim other physical keys.

Leave the label blank to show the automatic action and timer names.

A ProTimer action remains on this physical key until you remove or replace it in Elgato. To add one elsewhere, drag ProTimer Key onto a free position.

Help / Pomoć

Elgato's custom title and icon overrides take priority over plugin graphics. Clear the custom title and choose Reset to Default on the icon in Elgato to restore live graphics.

Srpski: klikni „Uredi ovde” da menjaš komandu ovog tastera u Elgato aplikaciji, zatim Save key. SET priprema sledeće vreme; ACTIVE je trenutno vreme. Preseti menjaju samo SET. START SET pokreće pripremu, PAUSE pauzira, RESUME nastavlja. BACK može vratiti prethodni profil samo ako ga je plugin prethodno aktivirao; za ručno napravljen profil koristi Elgato Switch Profile na slobodnom mestu.
